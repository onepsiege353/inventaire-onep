# Inventaire ONEP

**Application autonome de gestion, d'inventaire et de patrimoine des immobilisations de l'ONEP.**

- **100 % hors-ligne** : un seul fichier HTML, tout est intégré (logo, référentiel 853 biens + plan
  d'amortissement, QR codes, exports Excel/PDF).
- **Mobile & tablette** : interface adaptative.
- **QR codes professionnels** avec logo ONEP (nom du bien, détenteur, direction au scan).
- **Comptes** : `admin` / `onep2026` · `agent` / `inventaire2026`.

## Utilisation

1. Téléchargez [`inventaire-onep.html`](./inventaire-onep.html).
2. Ouvrez-le dans un navigateur (Chrome, Edge, Safari, Firefox).
3. Connectez-vous et commencez vos fiches, inventaires, étiquettes et rapports.


## 🌐 Synchronisation en ligne (optionnel)
Depuis la **7.8 Pro**, les agents peuvent activer la synchronisation automatique (fiches, projets,
mouvements, localisations) vers la base ONEP. La vue globale en temps réel est disponible sur la
**[console admin](console.html)** (voir `GUIDE_UTILISATION.md` → section 9).
