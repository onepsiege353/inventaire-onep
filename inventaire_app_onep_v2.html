🔗 Conciliation & Aide à la saisie — Trouver rapidement un code

Cet outil vous aide à aller vite lors de l'inventaire : recherchez un bien par mot-clé, obtenez immédiatement son code comptable, sa valeur nette, et le bouton pour créer une fiche en 1 clic. Vous voyez aussi les écarts entre le fichier 2026 et le plan d'amortissement en cours.

Recherche dans les 2 fichiers à la fois : fichier 2026 (codes BS-) et plan amortissement (codes ONEP-). Idéal lors de la saisie terrain.

⚡ Comment ces 2 listes vous font gagner du temps

  • Recherche instantanée : tapez 3-4 caractères (nom d'agent, type de matériel, n° compte) → vous obtenez le code exact, la désignation et la VNC sans ouvrir Excel.
  • Pré-remplissage en 1 clic : le bouton Créer fiche remplit automatiquement le formulaire (code, nature, valeur, date de mise en service, durée d'amortissement) — plus d'erreur de saisie.
  • Vérification de concordance : l'onglet Concilier vous montre en temps réel quel code existe dans quel fichier ; vous détectez les biens du plan d'amortissement absents du fichier 2026 (acquisitions récentes).
  • Export ciblé : chaque liste s'exporte en Excel (filtrée selon vos critères) pour remettre à la comptabilité, au chef de service, ou à l'auditeur.
  • QR codes : une fois la fiche créée, générez un QR code (onglet Immobilisations → QR Code) à coller physiquement sur le bien ; lors du prochain inventaire il suffit de scanner pour retrouver le bien.
  • Répartition par compte : la petite table à droite vous montre immédiatement combien de biens par compte comptable (244410 = mobilier, 245110 = véhicules, etc.) — utile pour répondre aux questions de l'auditeur en 2 secondes.

🔍 Inventaire physique — saisie terrain (codes BS- et ONEP-)

Principe : tous les biens de l'entreprise sont pré-chargés dans le référentiel (— biens : tous les BS- du fichier 2026 + les ONEP- < 300 000 F du plan d'amortissement). Scannez le QR code ou tapez le code d'un bien → il s'affiche instantanément → vous le marquez « Retrouvé » ou « Disparu ». Les trois listes (retrouvés / non répertoriés / disparus) sont exportables en Excel à tout moment. Plusieurs agents peuvent travailler en parallèle puis fusionner leurs sessions.

💡 Astuce : scannez le QR avec une douchette (envoi « Entrée » automatique) OU tapez les 4-5 derniers chiffres, la carte s'affiche.

🔗 Fusion des sessions agents

💡 Organisation multi-agents : 1) Chaque agent saisit son nom → scanne ses biens → clique « Exporter ma session (.json) » en fin de journée.
2) Le coordinateur importe tous les .json via « Fusionner sessions » → vue consolidée (un bien = un statut, « retrouvé » prime) → téléchargement des listes.
3) La progression est sauvegardée automatiquement dans le navigateur ; « Reset session » pour tout effacer.
